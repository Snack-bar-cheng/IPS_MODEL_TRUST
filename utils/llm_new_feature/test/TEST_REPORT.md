1. **首次使用前**：
   - 测试API连接是否正常
   - 确认网络环境稳定

2. **生成特征时**：
   - 设置合适的深度限制（建议2-4层）
   - 如果API调用失败，会自动重试（最多5次）

3. **检查生成的JSON**：

   - 确认operands格式正确
   - 确认深度符合要求
