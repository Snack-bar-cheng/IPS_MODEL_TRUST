# 改进的灰狼优化算法（Enhanced Grey Wolf Optimizer for GP）

## 概述

这是一个专门为遗传规划（Genetic Programming）设计的改进灰狼优化算法。该算法结合了分阶段动态策略、自适应机制和智能选择，旨在提升拟合时间和性能。

## 理论基础

详细的数学公式和控制公式请参考 [FORMULAS.md](./FORMULAS.md)

### 1. 分阶段探索-开发平衡

算法将进化过程分为三个阶段，针对50代进行优化：

- **探索阶段（0-20%，即0-10代）**：高探索性，使用较大的收敛因子（a ≈ 2.0），鼓励全局搜索
- **平衡阶段（20-70%，即10-35代）**：平衡探索和开发，收敛因子线性衰减（a: 2.0 → 0.1）
- **开发阶段（70-100%，即35-50代）**：高开发性，使用较小的收敛因子（a ≈ 0.1），精细局部搜索

### 2. 多层级引导机制

借鉴灰狼的社会层级结构：

- **Alpha层（5%）**：最佳个体，作为主要引导者
- **Beta层（10%）**：次佳个体，作为次要引导者
- **Delta层（15%）**：第三佳个体，作为辅助引导者
- **Omega层（70%）**：其余个体，根据引导进行更新

### 3. 自适应层比例调整

根据种群多样性动态调整各层比例：

- **多样性低时**：增加Omega层比例，增强探索能力
- **多样性高时**：增加Leader层比例，增强开发能力

### 4. 智能位置更新

不同阶段使用不同的选择策略：

- **探索阶段**：鼓励多样性，距离适中的个体有更高选择概率
- **平衡阶段**：使用指数衰减函数，偏向接近引导位置的个体
- **开发阶段**：使用更强的衰减函数，强烈偏向接近引导位置的个体

## 性能优化

1. **减少重复评估**：使用适应度缓存机制（可选）
2. **智能精英保留**：根据阶段动态调整精英保留比例
3. **高效选择算法**：O(n log n)复杂度，适合大规模种群

## 使用方法

### 在配置中启用GWO

在`main.py`的GP配置中，设置`enable_gwo=True`：

```python
"selection": {
    "strategy": "tournament",  # 当enable_gwo=True时，此字段会被忽略
    "tournament_size": 7,
    "hof_size": 20,
    "enable_gwo": True,  # 启用改进的GWO算法
    "gwo_type": "enhanced",  # "traditional" 使用传统GWO, "enhanced" 使用改进的GWO（默认）
    "gwo_config": {
        # 可选：自定义GWO参数
        "tau1": 0.2,
        "tau2": 0.7,
        "a0": 2.0,
        "am": 1.0,
        "af": 0.1,
        "rho_alpha": 0.05,
        "rho_beta": 0.10,
        "rho_delta": 0.15,
        "use_adaptive_layers": True,
        "diversity_threshold": 0.15,
        "adaptive_factor": 0.1
    }
}
```

### 默认配置

如果不提供`gwo_config`，算法将使用经过优化的默认参数，这些参数针对50代、1024种群大小进行了调优。

## 算法优势

1. **提升收敛速度**：分阶段策略确保在不同阶段采用最优的探索-开发平衡
2. **改善最终性能**：自适应机制和智能选择提升解的质量
3. **减少计算时间**：智能缓存和高效选择算法降低计算开销
4. **理论基础扎实**：结合灰狼优化理论和遗传规划特点

## 参数说明

### 阶段阈值
- `tau1` (默认0.2): 探索阶段结束比例
- `tau2` (默认0.7): 平衡阶段结束比例

### 收敛因子
- `a0` (默认2.0): 初始收敛因子，控制探索强度
- `am` (默认1.0): 中期收敛因子
- `af` (默认0.1): 最终收敛因子，控制开发强度

### 层比例
- `rho_alpha` (默认0.05): Alpha层比例
- `rho_beta` (默认0.10): Beta层比例
- `rho_delta` (默认0.15): Delta层比例
- Omega层比例自动计算：1 - (alpha + beta + delta)

### 自适应参数
- `use_adaptive_layers` (默认True): 是否启用自适应层比例
- `diversity_threshold` (默认0.15): 多样性阈值
- `adaptive_factor` (默认0.1): 自适应调整幅度

## 实验建议

1. **首次使用**：建议使用默认配置，观察效果
2. **调优**：根据具体问题调整`tau1`、`tau2`和收敛因子参数
3. **对比实验**：与锦标赛选择进行对比，评估性能提升
